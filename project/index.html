O que é GeekHub?

GeekHub é uma rede social feita para você criar listas de qualquer mídia que você consome.

Você pode usar para anotar filmes, séries, animes e até mesmo jogos. Tudo em um lugar só.

Assim fica mais fácil de se organizar e não precisar acessar vários aplicativos diferentes para cada lista.

Mas não é só isso. Aqui também é uma comunidade, onde você pode seguir pessoas, ver suas listas e compartilhar reviews com outros usuários!
